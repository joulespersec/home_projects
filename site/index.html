Where do you finish next year?

Every professional league sells the same story: this season's table is a verdict. But finishing position is a noisy signal. This view tracks every club's regular-season finish and where the same club lands the following year — so you can see how strongly the ladder pulls everyone back toward the middle, and which leagues resist it.

Post-season excluded. Each panel is a league's modern, stable-size era; positions are read within the frame teams actually compete in (conference, division, or a single table).

Consistency vs. regression, ranked

Correlation (r) between a club's finishing position and its position the next year, on a shared 0–1 scale. High = the order persists (consistency). Low =  last year barely predicts next year (strong regression to the mean).

How to read a panel

Horizontal axis: where a club finished. Vertical axis: where it finished the next season, with 1st at the top. Each column is a box plot of every club that started at that position.

If finishing order carried over perfectly, every box would sit on the dashed diagonal. Instead the boxes bend toward mid-table: top finishers slide down, strugglers climb. That bend is regression to the mean.

Method

  • Regular season only; play-offs and finals excluded.
  • Position is ranked within the competitive frame: conference (NFL, NBA), division (MLB), or a single table (EPL, AFL, NRL).
  • Each league is limited to a recent era with a stable team count so a given position means the same thing every year (shown per panel).
  • A club must appear in both seasons to count. In the EPL the bottom three are relegated, so positions 18–20 have essentially no "next year" in the top flight — the shaded band.
  • EPL / AFL / NRL tables are recomputed from match results (points, then goal-difference / percentage); administrative points deductions are not applied.
